Privacy Statement

Currency Converter does not collect, sell, share, or transmit personal information.

The Chrome extension stores your last selected amount, source currency, and target currency locally on your device using Chrome's storage.local API. The website version stores the same preferences locally in your browser using localStorage. This data is used only to restore your previous converter settings.

When you use the converter, your selected currencies and amount are sent directly to the Frankfurter exchange-rate API to calculate the result. Frankfurter provides European Central Bank reference rates and does not require an account or API key from this project.

Currency Converter does not use analytics, advertising, cookies, identity services, browsing history access, page content access, or background tracking.

For questions, open an issue at GitHub Issues.
